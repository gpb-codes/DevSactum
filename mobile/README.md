La app movil de DevSactum. Diseno glassmorphism, navegacion por drawer con 6 secciones, 22 pantallas y personalizacion total del tema.

---

## Funcionalidades

| | | |
|---|---|---|
| **Feed** tecnico con codigo | **Comunidades** y discusiones | **Chat** en tiempo real |
| **Bolsa de empleo** con IA | **Reputacion** y logros | **7 colores** acento + glass |
| **Freelancing** y portafolio | **Validaciones** tecnicas | **Membresias** PayPal |

---

## Desarrollo

```bash
flutter pub get
flutter run -d windows   # Escritorio
flutter run -d chrome    # Web
flutter run -d android   # Android
```

---

## Estructura

```
lib/
├── screens/     # 22 pantallas
├── widgets/     # Componentes reutilizables
├── providers/   # Estado global (4 providers)
├── services/    # 8 servicios API
├── core/        # Modelos, red, utilidades
└── config/      # Tema y rutas
```
