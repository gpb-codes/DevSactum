La experiencia web de DevSactum. Una SPA moderna con navegacion fluida, sidebar colapsable y 22 pantallas que cubren desde feed social hasta bolsa de empleo con IA.

---

## Funcionalidades

| | | |
|---|---|---|
| **Feed** con publicaciones y codigo | **Comunidades** tech colaborativas | **Chat** en tiempo real |
| **Bolsa de empleo** con IA | **Reputacion** y leaderboard | **Tema** 7 colores + glass |
| **Freelancing** y portafolio | **Validaciones** tecnicas | **Membresias** PayPal |

---

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000)

---

## Estructura

```
src/
├── app/          # Layout + ruta unica
├── components/   # 22 paginas + 17 UI components
├── context/      # Nav, Theme, Notifications, JobAuth
├── services/     # 8 servicios API
└── lib/          # API client, WebSocket, utils
```
